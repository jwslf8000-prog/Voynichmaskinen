# Voynich-PKT 0.1 – bigramkontroll och första textgissning

## 000011 – bigram/Markov-bevarande kontroll
Tre kontrollkorpora genererades med Voynichs empiriska teckenövergångar och originalens ordlängder. Samma lätta nyckelsökning användes på träning och fryst nyckel testades på blind foliofold.

Resultat train -> blind test:
- kontroll 1: 10,0274 % -> 10,9443 %
- kontroll 2: 10,1277 % -> 10,4240 %
- kontroll 3: 9,8481 % -> 10,1455 %

Voynichs tidigare motsvarande fold låg omkring 3,52 % -> 3,58 %.

Slutsats: enkel bigram/Markov-stavningsstruktur räcker inte för att återskapa Voynichs generaliserande låg-PKT-egenskap.

## 000012 – blind gissning av nästa PKT-profil
Första prediktionstestet använde den ursprungliga alfabetiska kodningen och fem folio-holdouts.
Mål: nästa ords exakta femdelade PKT-profil.
Modell A: alltid vanligaste träningsprofil.
Modell B: vanligaste nästa profil givet föregående ords PKT-profil.

Viktat:
- global baseline: 96,5041 %
- föregående profil: 96,5009 %

Den höga siffran är trivial: profilen 00000 dominerar. Föregående profil ger ingen förbättring.

Negativt resultat:
Rå PKT-profil är inte användbar för nästa-profil-prediktion i denna form.

Nästa test måste villkora bort 00000 och mäta aktiva händelser separat, alternativt använda en rikare PKT-representation/nyckelfamilj. Ingen exakt ordgissning får påstås fungera innan detta passerar.
