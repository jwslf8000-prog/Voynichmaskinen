# Stroke Grammar H2

## Motivation
Graphic Modules H1 found held-out structural evidence that EVA cth/ckh/cph/cfh behave as a coherent family and that the internal t/k/p/f identity acts as a distributionally meaningful modifier.

The next test must not invent visual primitives from those results.

## Independent external decomposition
Use the already-defined analytical alignment alphabet (aaa), documented by the Voynich transliteration project, as the external stroke/minim decomposition.

This is important because aaa was created for transliteration/alignment, not to fit the present statistical results. It independently decomposes Voynich shapes into stroke families and explicitly represents pedestalled gallows as connected component sequences.

EVA itself is analytical but intentionally does not decide which combinations are functional units. STA is synthetic and treats combined/ligature-like forms as units. The disagreement provides an independent representation axis for testing.

## Frozen H2 question
Do independently defined graphical stroke components carry reproducible distributional information on unseen folios?

Primary families:
1. bench/connector family underlying ch and pedestal forms;
2. gallows stroke families corresponding to t/k/p/f, including pedestal connection variants;
3. minim-run family underlying i/in/iin/...;
4. remaining common forms as controls.

## Guardrails
- No semantic assignments.
- Do not choose stroke decomposition based on prediction result.
- Do not infer historical derivation from visual similarity alone.
- Compare against frequency/complexity-matched alternative decompositions.
- Whole-folio holdout.
- Score per original EVA character or original glyph event so tokenization length cannot create a trivial win.

## Prediction
If Voynich is generated by a graphical construction grammar, independently defined stroke families should reproduce contextual/positional regularities across held-out folios, and related composite glyphs should factor into shared frame/stroke effects plus modifier effects.
